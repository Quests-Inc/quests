# Карта: деревья, расклады и зоны

Шапка карты разделяет поиск для добавления дерева, параметры **нового** дерева, общие фильтры видимости и действия.
Раскладка и глубина в меню «Новое дерево» действуют при добавлении. Для деревьев на холсте используйте ПКМ по карточке
или выделению → «Настройки деревьев». Общие карточки принадлежат первому дереву, которое их показало;
при выборе самого корня изменяется именно это дерево.

## Перезапись расклада

Кнопка «Записать сюда текущую карту» сначала читает сохранённый расклад и показывает добавленные и убранные сущности
(названия и ключи). Изменение названия сущности, перемещение карточки и сворачивание вложений не меняют её идентичность.
Подтверждение сохраняет именно показанный снимок; отмена ничего не записывает. Из журнала ничего не удаляется.
Для старых раскладов без `entities` состав приближённо восстанавливается из позиций и корней, без скрытых карточек;
об этом есть пометка в диалоге. После первой перезаписи появляется точный состав.

## Зоны

«＋ Зона» включает рисование прямоугольной области на холсте. Потяните по карте; Esc, ПКМ или отмена указателя
отменяют жест. Зона должна иметь ширину и высоту не меньше 40 единиц карты. Потяните подпись, чтобы переместить
зону, или нижний правый угол, чтобы растянуть. Клик по подписи открывает название, цвет, размеры и удаление.
При перетаскивании меняется только предпросмотр; координаты сохраняются при отпускании указателя.

Зоны — независимые аннотации: они не группируют сущности и не перемещают карточки. Слой находится под карточками,
масштабируется и перемещается вместе с картой. Зоны сохраняются в браузере и входят в личные серверные расклады;
при открытии старого расклада список зон пустой. Очистка карты также очищает зоны.
Максимум 200 зон, подпись до 120 символов. Свободное рисование пока не реализовано.

## MCP

`get_graph` читает связи вокруг сущности. Новый `graph_layout` работает с **личными сохранёнными раскладами** активного
пространства, а не с открытым холстом браузера:

- `list`: список; `get` + `id`: полный JSON состояния.
- `create` + `title`, `state`: новый расклад.
- `diff` + `id`, `state`: добавленные/убранные сущности; `legacy` сообщает о приблизительном составе старого расклада.
- `update` + `id`, `state`: предварительная разница без записи (`requires_confirmation: true`). Покажите её пользователю;
  только после одобрения повторите тот же запрос с `confirm: true`. Переименование через `title` без `state` записывается сразу.
- `delete` + `id`: предварительное подтверждение, удаление выполняется только с `confirm: true`.

`state` заменяется целиком, поэтому сначала прочитайте его через `get` и сохраните неизвестные поля.
Версия формата остаётся `v: 1`; новые необязательные поля совместимы со старыми раскладами.

```json
{
  "v": 1,
  "center": {"type": "quest", "id": 5},
  "roots": [{"type": "note", "id": 3}],
  "trees": {
    "quest:5": {"depth": 2, "layout": "tree"},
    "note:3": {"depth": 1, "layout": "radial"}
  },
  "depth": 2,
  "layout": "tree",
  "statuses": ["active"],
  "types": ["questline", "quest", "step", "note", "attachment"],
  "hidden": [],
  "expand": [],
  "folds": {"expanded": [], "loose": []},
  "positions": {"quest:5": {"x": 0, "y": 0}, "note:3": {"x": 600, "y": 0}},
  "sizes": {},
  "entities": [{"key": "quest:5", "title": "Квест"}, {"key": "note:3", "title": "Заметка"}],
  "zones": [{"id": "study", "title": "Учёба", "color": "#6a8fbf", "x": -100, "y": -100, "w": 900, "h": 500}],
  "view": {"cx": 300, "cy": 0, "k": 1}
}
```

`trees`: глубина 1–3, режим `tree`, `down`, `radial`, `layers` или `free`.
`entities`: состав видимой карты до сворачивания групп, без черновика и синтетических `cluster:*`; это источник разницы.
`positions` может содержать прежние позиции временно скрытых карточек, поэтому не заменяет `entities`.
`zones`: уникальные строковые `id`, подпись, цвет `#RRGGBB`, координаты левого верхнего угла и размеры в координатах мира.
Сервер хранит JSON непрозрачно, с действующими ограничениями размера и изоляцией пользователя/пространства.
